LocalAgentSociety

Every project folder on your Mac becomes an agent with a name, a color and its own voice. Talk to Claude or Codex out loud, hear what they did, and let them message each other — without stepping on each other's ports or voices.

Three commands to an agent that answers out loud

1

Install once

Clone the repo and run the installer. It builds the widget, installs the las command and starts the backend and the message broker as login services.

git clone … local-agent-society
cd local-agent-society
bash install.sh
2

Name a project

In any project folder, create its agent. It gets a free voice of your language and a color, and its widget appears on the Desktop you are on.

cd ~/Development/my-app
las agent new MyApp
3

Open a session

Start Claude through las. Dictations from the widget, and messages from other agents, now land in that session the moment they arrive.

las claude
# or las codex, las shell…

The widget is the agent's face

A small floating window in the agent's color, always on the Desktop where you work on it. It tells you what this Desktop is for, listens when you talk, and shows what the agent says back. Press a button to see what it does.

MyApp
fix the login redirectReporting: login redirect fixed, tests green.

🎙Microphone

    Speech bubbles on other Desktops

    When an agent speaks and its widget is on another Desktop, a bubble in its color slides in from the side where that Desktop lies. Click the text to go there, 🎤 to answer by voice without moving, ⌨ to type an answer, or 🔊 to silence that message — it turns into a red 🔇.

    Big when you are away

    While its Desktop is out of view, a widget can grow into a full-screen name banner, so Mission Control shows what each Desktop is for. Widgets that share a Desktop tile it as a mosaic instead of overlapping.

    One agent, as many sessions as you need

    An agent can have a Claude, a second Claude account, a Codex and a plain shell open at once. Each one is a session in 👥; the last one you used gets plain messages and the mic, unless you point them somewhere else.

    Continue, or start over, by voice

    Bring back a conversation you closed — or one started in a terminal — with las claude --headless --resume ID (just --resume takes this folder's latest) or las codex --headless resume --last. Say “new conversation” to start fresh.

    Every terminal says what it is doing

    Sessions carry a short title next to their runtime, shown in 👥 and in the terminal's own window title. ⌖ finds a session's terminal and brings it forward; ✕ closes it; 📄 opens the log of one without a terminal.

    Talk, and hear back what was done

    The whole round trip stays on your Mac: your voice is transcribed locally, the agent works, and its report comes back in its own voice — on the Mac, or on the phone if that is where you dictated from.

    A voice per agent

    Close to a hundred Kokoro voices, blendable (em_alex+am_onyx), each agent with its own and speaking its own language. las voices list shows who uses which.

    Never interrupted

    While any widget is recording, every voice waits: the clip playing pauses and the rest hold until you stop talking. Nothing you say gets talked over.

    Always a report

    Each turn ends with a short spoken summary that also lands in the widget's chat and the phone. If an agent forgets, the end-of-turn hook says it for it.

    Agents message each other, even across Macs

    Messages travel over vortexia, a small broker that runs next to LAS. Each agent has a mailbox that keeps messages in order until a session picks them up — up to 30 days, through restarts, nothing overwritten.

    las agent send --to Pulpo "the API moved to port 8010" --from MyApp
las agent send --to "System@uy-mac" "deploy is done"      # another Mac
las agent send --to MyApp --children "pull main and rebuild"  # every subordinate

    Same Mac

    Straight into the recipient's mailbox. Delivered the instant a session of it is open.

    Same network

    Macs find each other on the LAN and connect directly, broker to broker.

    Anywhere else

    Store-and-forward through a Nostr relay when there is no direct path — one Mac asleep or on another network. No code needs to know which one carried it.

    Aim at the right terminal

    las agent sessions --all maps every agent's open terminals and titles. Send to one with --session codex, to all with --all-sessions, or let the recipient's own choice decide (las agent target).

    They act on what they hear

    A message from another agent is treated like a request from you: the agent investigates, fixes, replies, and tells you in its report. You don't have to relay anything between terminals.

    A map of everything an agent works with

    Click 👥 for the agent's map: its sessions, its las-friends, and the repos and links you pin there, as mini widgets on one board. The 🎤 badge sits on whatever the mic talks to — drag it to another tile to move the mic.

    Hierarchy comes from folders

    An agent whose folder sits inside another's is its subordinate — nothing to declare. Each git repo inside a workspace can be its own agent, with its own voice. las agents --tree shows the whole tree.

    Archive, don't delete

    Put away a friend, repo or link with 🗄, or a whole agent with ⤓ (las agent archive). It leaves the panels but one step brings it back. las map global shows every agent on this Mac, archived ones included.

    The same society in your pocket

    Pair an iPhone from ⚙ → All widgets → Phones by scanning a QR code and comparing a fingerprint. Every agent of the Mac becomes a panel with its own mic and chat.

    Dictate on the phone and the Mac transcribes it; the agent's spoken answer follows you and plays on the phone. Pin where voices come out with ⚙ → Voice output (Auto, this Mac, or a phone). Revoke a phone from the same place.

    House rules every agent follows

    These rules are why many agents can share one Mac without fighting over it.

    🔌

    Ports come from the registry

    Before starting a server an agent checks las ports audit, takes a free port and claims it. A port held by another agent is asked for, never taken.

    🗣️

    One voice per agent

    No two agents on a Mac share a voice, so you can tell them apart by ear. las agent new picks a free one for you.

    🌐

    Speak the agent's language

    A Spanish voice never reads English. Each agent speaks and answers in its own locale, whatever language you write in.

    ⏳

    Take turns

    All speech goes through one queue, so voices never overlap — and nothing speaks while a mic is recording.

    📬

    No files for messages

    Agents talk only through vortexia mailboxes, never through files on disk or by typing into each other's terminals.

    🪪

    Say what you are for

    Each agent describes its scope at growing lengths — a name, a short and a long line, then longer documents — so people and other agents know what it does.
